# Assets de marque ANSUT

Logo officiel ANSUT fourni par l'équipe (fichier `logo_ANSUT_def.pdf`,
lockup vertical : icône « éventail » de points orange + sigle « ANSUT »
en bleu, avec la ligne institutionnelle « Agence Nationale du Service
Universel des Télécommunications-TIC »).

- `logo-ansut.png` — version compacte (icône + sigle, sans la ligne
  institutionnelle), fond transparent. Utilisée par
  `components/layout/SutaHeader.tsx` (hauteur réduite, la ligne
  institutionnelle ne resterait pas lisible dans le bandeau d'en-tête).
- `logo-ansut-full.png` — lockup complet (icône + sigle + ligne
  institutionnelle), fond transparent, pour un usage à plus grande taille
  (ex. pied de page, page « À propos », documents imprimés) si besoin.

Les deux fichiers sont extraits (rendu haute résolution, fond transparent)
du PDF officiel communiqué ; le PDF source n'est pas versionné ici (format
d'échange, pas un asset web).

⚠️ Ce logo diffère visuellement de celui visible sur la maquette de
référence fournie séparément (icône « combiné téléphonique » stylisé,
lockup horizontal compact) — cette variante horizontale n'a pas été
fournie comme fichier source à ce jour. Le PDF `logo_ANSUT_def.pdf` est la
seule source de logo réellement livrée par l'équipe ; c'est donc celle-ci
qui est utilisée, conformément au principe « jamais de recréation
approximative d'un logo à partir d'une image ». Si le lockup horizontal
de la maquette doit être utilisé, il faudra qu'il soit fourni comme
fichier source (SVG/PDF/PNG haute résolution) par l'équipe ANSUT.

Le wordmark « ANSUT CONNECTE » affiché à droite du header n'est **pas**
concerné par cette section : il s'agit du nom du produit lui-même
(texte), pas d'un logo graphique.
