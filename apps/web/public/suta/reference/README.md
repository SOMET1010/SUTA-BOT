# Référence de conception

Ce dossier est destiné à la maquette visuelle de référence (direction
artistique de l'écran Salon SUTA), à titre de conception uniquement — elle
ne doit **jamais** être chargée dans l'interface finale.

⚠️ La maquette fournie lors de la conception de cet écran (image jointe à
la consigne, non un fichier du dépôt) n'a pas pu être enregistrée ici par
Claude Code : une image reçue en pièce jointe dans la conversation n'est
pas automatiquement accessible comme fichier sur le disque de la session.

Pour la conserver comme référence dans le dépôt, l'équipe doit l'ajouter
manuellement ici, par exemple :

```
suta-salon-reference.png
```

L'interface a été reconstruite à partir d'une analyse visuelle de cette
maquette (composition, hiérarchie, palette, ambiance) — voir
`docs/architecture.md` pour le détail des décisions de design.
